Desenvolvido um sistema simples de controle de contatos feito com ASP.NET Core MVC.

## Sobre o Projeto

O **Controle de Contatos** é uma aplicação Full-Stack criada para facilitar o cadastro e a organização de contatos. O projeto aplica a arquitetura MVC e banco de dados para manter o código limpo e organizado, e conta com uma interface amigável construída com Bootstrap.

## Funcionalidades (CRUD)

- **Cadastrar**: Adição de contatos com validação de campos.
- **Listar**: Visualização em tabela responsiva.
- **Editar**: Atualização rápida de dados.
- **Excluir**: Remoção segura da base de dados.

## Tecnologias Utilizadas

- **Back-end**: C#, ASP.NET Core MVC, Entity Framework Core.
- **Banco de Dados**: SQL Server.
- **Front-end**: HTML5, CSS3 customizado e Bootstrap.

## Como executar o projeto

1. Clone este repositório:

```bash
   git clone https://github.com/anthonidaluz/ControleContatos.git
```

2. Abra o projeto na sua IDE (Visual Studio).

3. No ficheiro `appsettings.json`, verifique se a `DefaultConnection` aponta para o seu SQL Server local.

4. Abra o Console do Gerenciador de Pacotes e crie o banco de dados:

```bash
   Update-Database
```

5. Execute o projeto (F5).
